# Simple Interest Calculator

A lightweight, efficient tool designed to calculate the simple interest earned or paid over a specific period based on a principal amount and a fixed interest rate.

## Overview
This project provides a straightforward implementation of the Simple Interest formula. It is ideal for students, developers, or anyone looking to understand the basics of financial interest calculations through code.

## The Formula
The calculator uses the standard mathematical formula:

$$A = P(1 + rt)$$

Where:
* **P** = Principal amount (the initial sum of money)
* **r** = Annual interest rate (decimal)
* **t** = Time period (in years)

## Features
* **User-Friendly Input:** Easy entry for principal, rate, and time.
* **Instant Calculation:** Provides the total interest and the final amount immediately.
* **Validation:** Ensures that inputs are numerical and positive values.

## How to Use
1. Clone the repository.
2. Open the project in your preferred environment.
3. Input the **Principal amount**.
4. Input the **Annual Interest Rate** (e.g., enter 0.05 for 5%).
5. Input the **Time** in years.
6. Run the calculation to see the results.
